# 💊 Drug Interaction Checker

## 📌 Aim
To develop a Flask-based web application that detects potential drug interactions and provides safe alternative combinations for better healthcare decision support.

---

## 🧠 Project Description
The Drug Interaction Checker allows users to select multiple medicines and analyzes whether the selected drugs interact with each other. Based on the dataset, the system classifies interactions into different severity levels and provides appropriate warnings.

---

## ✨ Features
- 🔍 Check interactions between multiple drugs
- 🎨 Color-coded alerts:
  - 🟢 Safe
  - 🟡 Caution
  - 🔴 Dangerous
- 💡 Suggest safer alternative drug combinations
- 📊 Simple and user-friendly interface
